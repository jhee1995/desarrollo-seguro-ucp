La salida del modelo tampoco es confiable

output handling inseguro

# el modelo devuelve texto; el código lo usa a ciegas
resp = modelo.generar(pregunta_del_usuario)
eval(resp)        # RCE si el prompt lo manipuló
db.execute(resp)    # SQLi vía el modelo
render_html(resp)  # XSS almacenado

Si la salida del modelo entra a un intérprete, una consulta o el DOM sin validar, el atacante que controla el prompt controla esos sistemas. La salida de un LLM es entrada no confiable como cualquier otra.

Regla: trata la salida del modelo igual que la entrada de un usuario anónimo — valida, escapa, parametriza.

Cierra el círculo de la inyección: entra texto no confiable Y sale texto no confiable. Lo segundo se olvida más. Si tu agente genera SQL, HTML o comandos, eso pasa por las mismas defensas que vimos en las sesiones 3 y 4.
